# Сбор продаж за сутки и медиан Steam для снимка цен бота

Бот берёт объём продаж и медиану за 30 дней из файла цен Steam, который ему
пересылают в Telegram (см. `steam_snapshot.py`). Steam не отдаёт эти данные
адресам Render, поэтому их собирают отдельно — здесь.

## Откуда данные

Страница предмета `steamcommunity.com/market/listings/730/<имя>` перенаправляет
на страницу группы: в ней история продаж всех вариантов скина (износы,
StatTrak, Souvenir). Один запрос — объём за сутки и медиана за 30 дней по всей
группе. Запрос идёт обычным curl, без подмены User-Agent.

Steam отдаёт примерно 120–160 страниц подряд, потом отвечает 429 на часы.
Сборщик на 429 ждёт 1–4 минуты и пробует снова; прерванный запуск продолжает
с места остановки.

## Файлы

- `data/base.csv` — последний присланный боту файл (цены 26.10, объёмы, медианы).
- `data/medians.jsonl` — замеры со страниц групп (дописывает сборщик).
- `data/volumes.jsonl` — объёмы из priceoverview (343 скина, 28.10).
- `data/names_rest.json` — по одному имени на группу без замеров, 1 711 групп;
  сначала группы со скинами в полосе $2.5–100. 117 из них уже пройдены 29.10.
- `collect_groups.py` — сборщик.
- `build_file.py` — собирает `out/cs2_skins_steam_prices_history.csv` для бота.

## Как продолжить в новой сессии

Из этой папки:

```
python3 collect_groups.py 600      # поработать 10 минут; без числа — до конца
python3 build_file.py              # -> out/cs2_skins_steam_prices_history.csv
```

Длинный сбор — в фоне, циклом «сборщик 600 с → build_file.py», пока последняя
строка вывода сборщика не «готово». Готовый файл из `out/` переслать боту.
`out/`, `pages/` и логи в git не идут.
